# Examples / 示例

These examples show the intended shape of the skill output. They are not live rental recommendations.

这些示例展示的是输出结构，不代表实时房源推荐。

## Files

- [sample-output.zh.md](sample-output.zh.md): Chinese screening output for several South Bay candidates.
- [sample-output.en.md](sample-output.en.md): English screening output for the same style of task.

## How To Use

Install the skill, then paste one of the prompt patterns from [docs/prompt-library.md](../docs/prompt-library.md). Replace the apartment list with your own candidates and ask Codex to use `$bay-area-rental`.
