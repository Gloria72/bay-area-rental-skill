# Roadmap / 路线图

Ideas that would make the repo more useful and more discoverable.

## Content

- Add anonymized sample analyses for common South Bay apartment clusters.
- Add a "known risky geography" page for rail, expressways, SJC, Levi's, and public garages.
- Add a glossary for `Type I`, `podium`, `5-over-2`, `Luxer One`, `tailgating`, and `courtyard-facing`.
- Add more English examples for non-Chinese-speaking renters.

## Skill Quality

- Add short evaluation prompts to test whether the skill refuses to over-recommend Cobalt, Naya, Catalyst, Lofthouse, Prado, One South Market, and other corrected candidates.
- Keep `SKILL.md` short and move apartment details into references.
- Periodically prune stale property notes or mark them as historical.

## GitHub Presentation

- Add more real but anonymized sample outputs.
- Add a social preview image.
- Keep README badges, topics, and description up to date.
- Encourage issues for new property notes, but require evidence and privacy redaction.
